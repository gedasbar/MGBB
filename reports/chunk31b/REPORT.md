# Chunk 31b: Shipyard, part 2 (screen, art, debug cell mode)

Branch `chunk-31b` (from `origin/main` c14ee24, 31a merged). Design note: `docs/shipyard.md` section 7. Decisions 527-537. Contact sheet: `reports/chunk31b/sheet_31b.png` (360 x 740, made by `e2e/sheet-chunk31b.cjs`).

## What was built
- **Entry** (step 1): the hub's SHIPS tab has a SHIPYARD entry pinned under the tab strip (it does not scroll). Before ring 150: padlock, "Locked: Frontier ring 150", the Cores balance; a tap says when it opens. After: "Design a custom ship from chunks", a tap opens the screen. Valid, fully owned designs are "Custom 1 / 2 / 3" in the hull list (31a) and now draw with the custom art.
- **Screen** (step 2, `src/screens/ShipyardScreen.ts`): header with Cores, design buttons 1 / 2 / 3 and a name box (DOM text box), the 4 x 4 grid of chunk slots drawn as their cell patterns, a status strip (VALID or the first plain-language error, the named slot outlined red, then cells / ejectors / pulses / shot speed / size class), Undo / Redo, "Use this ship" (greyed unless valid and fully owned; a tap on it says why), and the chunk palette (the block palette's own `TilePalette`, new `drawFace` option: pattern, free-copy badge, yellow dot, Place / Buy in Cores, Remove tile). Place / replace / remove / undo / redo save at once. Using a ship opens the builder on it; `BuilderModel.reloadHull()` keeps the builder in step when a design changes.
- **Art** (step 3): `CUSTOM_SHIP_ART`, one fixed 25c-style drawing for every custom ship and the debug test hull (broad rectangular hull, short nose, side plates, two engines with flames, flat greys, three accent pieces in one teal constant), scaled by size class. Used in flight, the hull picker and the hub. Fixed on the way: ship textures were cached per hull id (a custom hull changing size class would have kept the old size); the key is now `id@WxH`.
- **Debug cell mode** (step 4, `DEBUG_ON` only): grid of single cells up to 12 x 12 with W- W+ H- H+, tap cycles outside / buildable / generator / ejector, `validateHullLayout` errors, Export (ROWS text in the `hullLayouts.ts` shape, copied when the browser allows and shown in a box), Fly test (Free Fly with a throw-away `celltest` hull, nothing saved).
