# Chunk 31c: Shipyard fixes (fixed generator, rotation, builder-like screen, sandbox)

Branch `chunk-31c` (from `origin/main` d059af4, 31b merged). Design note: `docs/shipyard.md` section 8. Decisions 538-544. Contact sheet: `reports/chunk31c/sheet_31c.png` (360 x 740, made by `e2e/sheet-chunk31c.cjs`).

## What was built
- **Fixed generator** (`GENERATOR_COLUMN` = 6, column 7 of 12): a 13th row under the build area, drawn with the builder's generator art. The Generator chunk is removed (15 chunks left). Saves that owned Generator chunks get the Cores back (60 x 1.5^i for the i-th copy) and the chunk leaves their designs (save migration in `sanitizeShipyard`, idempotent).
- **Looser validity** for designs, `validateHullLayout` (official hulls, cell mode) and chunks: "generator in the bottom row" and "nothing above an ejector" are gone; kept: one generator, a cell above it ("The cell above the generator must be part of the ship" for custom ships), everything joined, at least one ejector (new in the official validator). All 19 official hulls pass.
- **Rotation:** every placed chunk turns 0 / 90 / 180 / 270 (`Design.rot`, `rotateRows`, `ShipyardEditor.rotate`); placed at 0; one undo step each. **Save version 15** (the rotation list; version asserts in about 30 tests and 4 e2e scripts moved 14 -> 15).
- **Screen like the builder:** the builder's `GridRenderer` draws the assembled ship (cells, ejectors with the 25a inlet art, the generator and the red line); a selected slot has the builder's yellow outline; toolbar Clear / Rotate left / Rotate right / Undo / Redo in the builder's button style, keys R / Q / D / Ctrl+Z / Ctrl+Y / Esc; palette = the builder's bottom sheet (tap a tile, tap again to place, Buy in the sheet, no Place button); error line above the stats strip under the grid; the long help line is gone. The grid refits above the sheet while it is open.
- **Debug sandbox:** cell mode "Build & fly" opens the layout in the real builder as hull `celltest`, all blocks free (99 each, top level), SANDBOX banner with EXIT, nothing written to storage; EXIT returns to cell mode with the layout intact. Export and Fly test stay.
