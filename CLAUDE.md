# Mitosis Gun Builder (working title)

A mobile-first browser game inspired by the modular circuit-shooter "Miner Gun Builder". You design a gun as a circuit inside a hull grid, then fly and shoot. Original ideas here: rock enemies that crack and split (mitosis), many projectile-changing blocks, and campaign walls you carve a lane through.

The owner is not a programmer. They test in the browser and describe what they see. Prompts come in chunks (e.g. "CHUNK 9a"). Follow each chunk's steps in order.

## Stack and commands
- TypeScript (strict), Vite, PixiJS v8, Vitest, Playwright (headless Chromium, scripts in `e2e/*.cjs`).
- Check `package.json` for exact script names. Typical: `npm run dev`, `npx tsc --noEmit`, `npm test` (= `npx vitest run`), `npm run test:e2e` (quick smoke set of browser scripts, needs `npm run dev` running), `npm run test:e2e:all` (every `e2e/*.e2e.cjs`, runner `scripts/run-e2e.cjs`), `node e2e/<name>.e2e.cjs`, `npm run balance-wall`, `npm run balance-econ`, `npm run balance-damage` (7 min; `PART=a|b|c|d`, `QUICK=1`), `npm run difficulty-audit` (content vs what a player owns, `docs/difficulty-audit.md`; about 1 min from the committed bot cache in `reports/difficulty-audit/`, `FORCE=1` flies the bots again, about 40 min), `scripts/block-audit.ts`, `npm run perf-legendary` (Mirror on a big hull, update times), `npm run perf-profile` (chunk 21b: where a frame goes, in Node, for the owner's slow build; `POOL=8000` tries another pool size), `node e2e/performance.e2e.cjs` (the same build in the browser: sim, sprite sync and draw call), `npm run interaction-audit` (every pair of shape, effect and legendary blocks).
- Never run `playwright install` (Chromium is preinstalled). npm and pip work; most other network access does not.
- Dev URL flags: `?debug=1` (debug panel, seam line), `?stats=0|1` (stats overlay, also toggled with the backtick key), `?bg=<id>|off` (force or remove the background). Dev hook: `window.__mgbm`.

## Game design (current state)
**Circuit model.** The Generator (fixed hull cell) always emits a red signal that travels through empty cells as implicit straight pieces. Blocks transform packets in path order and output relative directions (F/L/R). Every block has a STORED orientation and the compiler only reads it (chunk 16a): a block is entered from the side it faces, any other side is a dead end. A new block works out its direction once at placement (it faces the way the signal reaches that cell, `src/engine/orient.ts`) and keeps it; placing, removing or moving a block never re-orients another one. The Auto-orient button is a one-time placement action on the selected block only (the orientation is stored, never recomputed afterwards); Rotate turns it by hand. Old saves (builder save v2, blocks in "auto") are oriented once on load against the circuit as saved. Lines may cross freely, but a block shared by two signals only passes the one entering from the side it faces. Same-axis overlap cuts the later signal. The compiler is in `src/engine/compiler.ts`.

**Blocks.** Data in `src/data/blocks.ts`. Categories: Pathing (blue), Damage (salmon/orange), Modifiers (purple), Status (teal), Mitosis (amber, Free Fly rock mechanics), Legendary (lime, chunk 20a; 66 blocks are shown in all, 13 of them the chunk 20b motion blocks). Only eight blocks have levels (Flat+, Percent x, Lucky Strike, Jackpot, Gambler's Gate, Shield-Breaker, Armor-Piercer Tip, Pure Converter, chunk 16c-2); every other block has one level and runs at its fixed level (`BlockDef.fixedLevel`, table in `src/data/blockEconomy.ts`; the compiler reads it through `powerLevel`). The builder palette and the Shop block list are one shared tile component (`src/builder/tilePalette.ts`): a single scrolling list ordered by category, then data order, no tabs, no category-coloured tile outline, 5 tiles per row. **Shop marks (17a):** brightness never means "owned" in the Shop (only locked tiles are dimmed, with the padlock; the count says what you own); a small yellow dot (#f2c230) in the bottom-right corner of a tile means the next copy can be paid, the cap is not reached and it is not locked (`copyAffordable`); the same dot marks an affordable unowned hull in the hull picker. The builder sheet has no X and no Place button: tap the selected tile again to place it, tap the circuit to close. Every block's copy cap, base price and growth are one table, `BLOCK_ECONOMY` in `src/data/blockEconomy.ts` (16c-2, price family B from `docs/economy-audit.md`): copy price of the n-th copy = base x growth^(n-1) (growth 1.30 normal, 1.15 cheap blocks, 1.20-1.35 for Flat+, the chance blocks and Overclock), upgrade price = base x 2.0 x 2.2^(level-1). Caps: Percent x 10, Flat+ 10, Lucky Strike 6, Jackpot 6, Gambler's Gate 4, Overclock 3, Turn Left / Right 20 each (growth 1.20), Splitter 2 and 3 15 each (growth 1.35 and 1.45; 17b), every status and Mitosis effect block and every block whose extra copy would do nothing 1; the shape blocks that stack have no cap. The shop sheet shows owned / cap and Buy reads "Max" at the cap. **Percent x** is x1.5 per copy at L1 to x3 at L10, geometric in the level; **Gambler's Gate** is 40% (L1) to 50% (L3) for x3. **Stacking rule (engine):** every copy of Piercing, Bouncing, AoE Circle / Rectangle, Chain Lightning, Homing, Fork on Impact, Boomerang, Orbit or Mine on a signal's path adds a step (`docs/economy-design.md`, step 5; helpers in `src/engine/effects.ts`); status and Mitosis effects read one level and do not stack. The game shows two short player lines per block (`src/data/blockText.ts`, 19b: one line of at most 60 characters, and for stacking blocks a dimmer "+1 copy: ..." line of at most 40); the long technical text is `BlockDef.desc` and `docs/blocks.md` (`npm run blocks-doc`, regenerate after changing a block). **Interaction rules (17b, `docs/interactions.md`):** every on-hit effect has a trigger in ONE table, `TRIGGERS` in `src/engine/triggers.ts` (status/Mitosis effects: every hit; AoE: every hit (19a; the `shot_end` rule and `ProjectileSystem.retire` are kept but unused); Fork on Impact and Gravity Well: first hit; Chain Lightning: every hit, at most 3 chains per shot; fork copies carry statuses and movement blocks only, no AoE, Fork or Chain). AoE costs the whole shot 5% per extra copy and the builder's estimate shows it. **Chunk 19a:** Piercing is a count, each copy lets the shot through one more target (1 copy = 2 targets) at full damage (`PIERCE_DAMAGE_KEEP` in `effects.ts`), and the shot ends after its last hit; because pierce and bounce are finite, AoE fires on every hit (`docs/interactions.md` section 5). AoE Rectangle is measured in wall cells (`aoeRectCells`: 1 copy 1x3, then alternately a row deeper behind the hit and two wider: 2x3, 2x5, 3x5, 3x7), the Circle's base radius is one cell (`AOE_CIRCLE_CELLS`). Extra copies: Homing a longer seek range and wider cone (19a nerf: one copy 328 px / 33 degrees, three copies the old 400 px / 60), Orbit one more pass, Mine one more mine (up to 3 extra). `npm run interaction-audit` flies every pair of shape/effect blocks (`docs/interaction-audit.md`). **Legendary blocks (20a, `docs/legendaries.md`).** Twelve blocks, one copy each, no upgrades, three per Frontier direction at rings 100 / 200 / 300 (`UNLOCK_BLOCKS` in `src/frontier/unlocks.ts`; a passed or cleared square at that ring or beyond in that direction). They cost Medals AND credits (`LEGENDARY_PRICE_BY_RING` in `blockEconomy.ts`: 15 Medals + 8K, 25 + 65K, 40 + 300K; the Shop sheet shows both, Buy and the yellow dot need both). North: Frontier Echo (+10% of the furthest ring), Payload (+25), Lone Shot (x2 with one shot of yours alive, x1 from ten). East: Last Breath (x2 in the last second of a shot's life), Zigzag (turns every 0.2 s, +5% a change), Heavy Round (x2 at normal speed to x5 at 0.2x). South: Hollow Core (+10% per empty buildable cell), Idle Barrels (+3 per unreached ejector), Waypoint (x1.1 per turn passed). West: Rebound (x4 if the previous shot through the block was weaker), Mirror (every shot cloned), Fuse (10 shots in, one out with double the total). The numbers are in one section of `effects.ts`; compile-time ones read `CompileContext` (furthest ring, empty cells, idle ejectors, `packet.turns`), Lone Shot / Rebound are Gun ops, Fuse is the Capacitor stage with n=10, Mirror is made in `Gun.spawn` (never from a hit, so never cloned again; `TRIGGERS.mirror`). **Frontier unlocks are legendary-only (20b).** The Frontier unlocks the twelve legendary blocks and nothing else (`UNLOCK_RINGS` = 100 / 200 / 300, three blocks per direction; the map draws only those three rings). **Campaign-tier locks (20b, `src/data/tierLocks.ts`, `TIER_LOCKS`):** a block can need a PASSED campaign tier (padlock and text "Pass tier N" in the Shop and the builder picker, same as the Frontier lock; a "Unlocked: X" toast when a tier passes). Grandfathering: a save that owns a copy keeps buying, a save that had reached the block's old Frontier ring (`LEGACY_RING_GATES`) keeps it. 26 blocks have a tier: Accelerator 5, Brake 15, Scatter 15, Upturn 20, Align 25, Extender 30, Centreline 40, Ship Magnet 45, Persist 50, +1 Projectile 10 (21a) and the 16 ordinary blocks that used to sit at Frontier rings 10 / 25 / 50 (Cleaver 5 ... Chain Lightning 60, full table in `docs/blocks.md`). **Motion blocks (20b, `docs/motion-blocks.md`):** thirteen Modifier blocks that change how a shot moves: Curving Left, Angle Left / Right (15 degrees a copy, max 60; `packet.angle`), Accelerator (x1.5, cap 3, ceiling x4), Brake (x0.7, floor 0.2; Heavy Round reads it), Scatter (random cone +-30, +15 a copy, max 60), Upturn (turns back to straight up after 0.4 s), Align (straight up after a surviving hit), Extender (life x2 a copy, `pool.life`; Last Breath follows it), Centreline (pull toward the x the shot was fired from), Ship Magnet (the old hidden `magnetized` block; pull toward the ship, speed capped at the launch speed), Persist (spends the damage a target had left, goes on through kills). (Reverse was removed in 21a.) A fast shot is checked along its whole step (`ProjectileSystem.sweep`, swept hit test). Free Fly now retires every shot at its `life`. On a hit the order is Persist, Piercing, Bouncing, end (`docs/interactions.md` section 7). The numbers are one section of `effects.ts` ("Chunk 20b"). Save version 9 until 21a (now 10). More blocks are hidden until added by a chunk.

**Chunk 21a (`docs/chunk21a.md`).** **+1 Projectile** (`plus_one`, Damage, cap 10, price 110 x 1.5^(n-1), tier 10): adds one NEW shot to the lane with base damage (1 + hero level + captain base) and none of the blocks before it; every block after it works on both shots; each copy one more shot. Compiler: `Packet.extras` (the shots made so far; each later block is applied to them too), one recipe per shot at the ejector, `EjectorRecipe.lane` = sideways offset (`LANE_GAP` 8 px, centred). **Curving Left / Right and Random Curve stack** (cap 4): 30 degrees a second and 45 degrees in all per copy (`pool.curved`), Random Curve's weave rate 30 x copies. **Upturn overrides** after its delay (0.4 s, x0.75 per extra copy): Curving, Random Curve, Homing, Centreline, Ship Magnet and Zigzag stop steering; not Orbit before launch, a waiting Mine or a Boomerang's way back. **Builder keys** (`src/builder/keys.ts`, `keyAction` pure; listed in the help): R / Q / Shift+R rotate, D / Delete / Backspace delete, A auto-orient, Ctrl+Z undo, Ctrl+Y or Ctrl+Shift+Z redo, Esc close/deselect, F fly. **Run summary** shows "Best shot" and "Average DPS" (`ProjectileSystem.runStats`, `src/ui/runStats.ts`; as two more rows of the same style since 21b). **Shot looks by damage** (`src/ui/shotLook.ts`): log bands 10 / 100 / 1K / 10K; the bands were redrawn in 21b (below). The 16 blocks that moved to campaign tiers were repriced to about 2.5 runs at their tier (5 for Overkill Spill, Residue Seed, Chain Lightning).

**Chunk 21b (`docs/performance.md`, DECISIONS 372-384).** **Performance.** The owner's slow build (10 +1 Projectile, Mirror, Fork, 2 Extender, 2 Bouncing, 3 Homing) was profiled first (`scripts/perf-profile.ts`, `e2e/performance.e2e.cjs`, builds in `scripts/lib/perfBuild.ts`): on the tier-100 wall Homing cost 21 of 22 ms a frame at 4,000 shots (every homing shot listed every block in 400 px, every frame); in Free Fly the cost was the hit test's allocations. Fixed: **Homing keeps its target** (alive, in range, in the cone) and with none searches at most every 0.1 s, the first search staggered by pool slot (`homingTurn`, `HOMING_RETARGET`, `HOMING_STAGGER`); the search is a radius query on the field (`TargetField.nearestInCone` / `byId`, `ListField` is the brute-force reference for plain lists); `SpatialHash` is flat typed arrays with `queryInto` (no list per query); the world keeps one hash and one `EnemyField` (`refresh()`); the modifier-list facts are cached per list (`ModInfo`, `use()`), no per-shot `find`; `ProjectilePool.spawn` starts from a free-slot hint. Wall at 4K shots 22.5 -> 2.95 ms, Free Fly 3.5 -> 2.3 ms (Node); in the browser the wall at a full pool went from 3 fps (a catch-up spiral, 268 ms of sim) to 26. **Graceful overload** (`CONFIG.OVERLOAD`): new shots are refused as the pool fills, in this order: fork fragments (80 % of the pool), Mirror clones (88 %), the extra shots of +1 Projectile (`EjectorRecipe.extra`, 94 %), normal shots only at 100 % (`pool.admits(kind)`, `pool.refused`); from 85 % plain shots that are off-screen (`projSys.viewCx / viewHalfW / viewTop / viewBottom`, set by the wall screen from the camera) and have hit nothing for 1.5 s expire first (`expireStale`, at most 400 a frame). **The pool limit stays 4,000** (`CONFIG.CAPS.PROJECTILES`): at 4K the build is already at about 8 ms of sim plus render in the browser. **Shot looks (redrawn):** five bands, each its own shape and colour: under 10 a thin cyan dash, 10-99 a longer pale-cyan bar, 100-999 a yellow diamond, 1K-9.9K an orange bolt, 10K+ a magenta four-pointed star (`SHOT_LOOKS` in `src/ui/shotLook.ts`); Orbit, Boomerang and Mine keep the plain bar (`PLAIN_LOOK`). `src/ui/shotSprites.ts` draws every shot of a pool for both fly screens: one white texture per shape, tinted; texture, size and colour are set only when a shot's look changes; shots outside the view are hidden. **Run summary:** Destroyed / Time / Result (or the four Free Fly rows), Best shot and Average DPS are rows of one style, then the Total credits line, the captain line and the buttons (at y 800, `SUMMARY_BUTTONS_Y`; e2e scripts tap y 832).

**Chunk 22a: the Skill tree (`docs/skills.md`, DECISIONS 385-395).** The Skills tab (was "coming soon") is a pan / zoom map of 55 hexagonal nodes: a free start node and six paths (Routing, Flight, Volley, Impact, Firepower, Salvage) of 7 normal nodes and 2 capstones each (the capstones upgrade a legendary block and can be bought before the block is owned). **Points** come from the furthest Frontier ring (the number Frontier Echo reads): one per 25 rings up to ring 250, then one per 50 (`skillPointsFor`, constants in `src/skills/constants.ts`); points are never stored (free = paid by ring - owned nodes). A node costs 1 point and must touch an owned node (the start counts). **Respec** takes every node back for 10 Medals (5 with the Salvage node), with a confirm dialog. **Save version 11** adds `skills` (owned node ids). **Data:** `src/data/skillTree.ts` (names, texts with `{key%}` placeholders, `fx` numbers; layout follows from path and role); `SkillEffects` (`src/skills/effects.ts`) is one additive record that reaches the game through `CompileOptions.skills` / `CompileContext.skills` (damage per block, so the builder estimate includes it), `RunModifiers.skills` -> `ProjectileSystem.skills` (hit pipeline and Gun) and the store (caps `capWithSkills`, credits `creditBonusMul`, extra Medal on medal squares, hero level cost `heroCostWith`, respec cost). Screen: `src/screens/SkillsScreen.ts`, pure map maths `src/skills/layout.ts`, rules `src/skills/rules.ts`. Test: `tests/skills.test.ts`, `e2e/skills.e2e.cjs`.

**Hulls (17a, `docs/hull-ladder.md`).** `src/data/hulls.ts` (`HULLS`: price, pulses/s, shot speed, size class; `HULL_ORDER` = price order) and ALL 19 layouts in `src/data/hullLayouts.ts` (`HULL_ROWS`, price order, legend and an `idea:` line per hull at the top; checked by `validateHullLayout` in `src/data/hullValidate.ts`, which explains mistakes in plain words; how to edit: `docs/EDITING.md`; `.` outside, `_` buildable, `G`, `E`). 19 hulls: Dart (free, 1 cell), Twin 70, Prong 350, Wisp 700, Hornet 1.1K, Lancet 1.7K, Kestrel 2.6K, Mantis 3.9K, Bastion 6.2K, Halberd 11K, Corvette 19K, Trident 33K, Galleon 58K, Shuttle 96K, Spire 190K, Leviathan 330K, Fan 500K, Citadel 820K, Zenith 1.3M (cells 1 to 80, ejectors 1 to 10, shapes that are puzzles: U, dog-leg, hook, diamond, ring with a hole). The generator only emits upward, so the cell above it is always buildable. Every basic shot deals 1; the pulse rate is the hull stat (Dart 2/s up to Lancet / Shuttle 5/s); `shotSpeed` is a per-hull multiplier on projectile speed (Gun.speedMul). Ejector offsets from the ship centre are scaled by `FIRE_OFFSET_SCALE`. **Size classes** (`SIZE_CLASSES`): small art 26 x 34 / hit radius 8, medium 34 x 44 / 9, big 44 x 56 / 10, huge 56 x 70 / 11; `World.hitR` / `WallWorld.hitR` read it. Art of the 14 newer hulls is generated from their layout (`generateShipArt`). The hull info sheet shows a trait line from the ejector count (`hullTrait`: one ejector = single lane, three or more = wide coverage). Hulls are bought in the **builder's hull picker** (ship button: all 19 by price, unowned dimmed with price, info sheet with Buy); the Shop is blocks only. The `ownedHulls` list is unchanged (saves still version 8, unknown ids ignored). Pricing: `scripts/hull-pricing.ts` + `hull-pricing-fit.ts` (sensible builds in `src/debug/hullBuilds.ts`).

**Fly screens.** The ship has an INVISIBLE circular hit point (`HIT_RADIUS = 8` for a small hull, 9 / 10 / 11 for medium / big / huge, so a big hull is harder to dodge); the small ship art is about 26 x 34 px so touching any part of it feels fatal. Spawn safety: the ship waits at bottom-centre until the first pointer move, eases in over 0.25 s, then has 1.0 s invulnerability.
- **Free Fly:** one fixed screen width, no wrap, no horizontal scroll. Rock enemies confined inside the screen. Rocks crack as they take damage and split into smaller rocks (`src/engine/mitosis.ts`). Backgrounds rotate every 3 minutes.
- **Campaign wall tiers (1-100):** a wall of blocks approaches at a constant base speed and loops sideways like a cylinder (`LevelDef.wrap`, 21 columns, camera edge-push). The ship is one-hit: touching a live block ends the run. Flying near the top of the screen speeds the wall up to about 4x (`TOP_ZONE`, `BOOST_MAX`). Results: CLEARED (all blocks destroyed, first time = +1 Medal), PASSED (ship flies `PASS_MARGIN_CELLS` = 1 cell past the wall, unlocks next tier, no Medal, nothing drawn for it), CRASHED. Results are instant (16a): the decision is the pure `wallResult` (`src/wall/result.ts`, cleared beats passed), the world and the ship freeze and shots in flight are dropped, and the result screen follows after `RESULT_DELAY_CLEARED` / `_PASSED` (0.4 s); a crash 0.3 s, a Free Fly death 0.7 s. Frontier Free Fly squares clear the same way at the full time. Credits are paid for blocks destroyed in every run. Tiers unlock in strict order. Spike tiers (about 1 in 8) have 1.6x block HP and a unique background. Armor appears from tier 11, shields from tier 21. Every 10th tier is a named milestone.

**Economy.** Credits (yellow) for kills; Medals (one per first full clear, plus the Free Fly wave milestones 5/10/15/20/30/40/50) are a spendable balance used by Captains. Rewards 1.05^tier. **Small numbers (14a, `docs/balance-damage.md`):** Flat+ +1 a level; wall block HP 2 x 1.13^(tier-1) up to tier 30, then x1.06 a tier to 40, x1.065 to 60, x1.0525 to 100 (18b; tier 100 is about 3.4K, flat after; `BLOCK_HP_SEGMENTS`), whole numbers; rock HP 5 at tier 1, Free Fly waves x1.25 HP each up to wave 20, then the total growth per wave is x1.19 / x1.08 / x1.06 to waves 30 / 40 / 50 and after (18b, `WAVE_SLOW_GROWTH`, `src/data/waves.ts`); Frontier block HP follows the campaign curve at the ring's effective tier to ring 250, then x1.018 a ring, and Frontier walls need a cheapest column of at least the median (`FRONTIER_LATE_GROWTH`, `MAP_MIN_COLUMN_SHARE`; the campaign keeps 0.3), so passing a Frontier square costs more than passing a campaign tier (docs/difficulty-audit.md section 9); damage multipliers on one line multiply at full strength (14a's diminishing rule was removed in 14b). **No damage clamp (16c-2):** projectile damage, the Delay Line queue and Residue cloud damage are Float64; a NaN or non-positive hit is dropped (`!(damage > 0)` where a pulse's damage is decided and in `applyDamage`); an Infinity hit simply kills and `Infinity x 0` is written as 0 (`mulSafe`), so HP can never become NaN. Numbers on screen go through `src/ui/format.ts`: plain below 1000, then K, M, B, T, then scientific (1.2e45), never the words Infinity or NaN. Saves are version 11 (22a adds the owned skill nodes, `skills`); version 10 (21a removes Reverse: owned copies are refunded by the price formula, placed copies leave the saved circuits, a one-time message says so; `econ/migrate.ts` `REMOVED_BLOCKS`); version 9 (19a adds the best credits earned in one run per campaign tier and Frontier square, `wallBestCredits` / `squareBestCredits`, shown as "Best earned" in the tier and Frontier panels and as "New best earnings!" on the run summary; older saves start with none); version 8: upgrades that no longer exist and copies over the new caps were refunded at the old prices on load (`src/econ/migrate.ts`, old prices frozen in `src/econ/legacyPrices.ts`).

**Captains (13a).** `src/captains/` (data, modifiers, state; design in `docs/captains-design.md`). Four captains (Cadet free, Bulwark, Gunner, Pathfinder), one active at a time; hero level (no cap since 16c-2; +0.5 base damage each, chunk 14a; the Medal cost of level n is max(1, round(1.2^(n-1)))) and 4 option tiers of 2 options (unlock at 0/300/1500/6000 lifetime kills of that captain, 2/4/7/11 Medals); one active option per tier, free switching among owned ones. `computeRunModifiers` turns them into a `RunModifiers` struct that `World` / `WallWorld` read at run start (neutral = no change). Captain tab: `src/screens/CaptainScreen.ts`. Cheats in the debug panel: Captains group. `npm run balance-captains`.

**Art language.** Sharp geometric shapes, flat fills, no gradients or textures, no glow. Block plates: nested squares (outer #55555a, mid = category colour darkened, inner #26262a) with a light-grey (#d4d4d8) entry bar and exit triangles. Ships are shades of grey with small coloured pieces. Rocks use warm muted tones with generated cracks. UI theme in `src/ui/theme.ts` (grey #1c1c1e background, panels #2a2a2d, yellow currency #f2c230).

**Sound, pause, settings (12a).** Sound effects are synthesized in code (`src/audio/`, data in `sounds.ts`, no files, no music yet); `sfx.play(id, {pitch, gain})`. Fly screens expose `pausable`; pause/settings UI is `src/ui/overlays.ts`. Dev hooks: `window.__mgbmSm` (screen manager, overlays), `window.__mgbmSfx` (engine, stats).
