# Mitosis Gun Builder (working title)

A mobile-first browser game inspired by the modular circuit-shooter "Miner Gun Builder". You design a gun as a circuit inside a hull grid, then fly and shoot. Original ideas here: rock enemies that crack and split (mitosis), many projectile-changing blocks, and campaign walls you carve a lane through.

The owner is not a programmer. They test in the browser and describe what they see. Prompts come in chunks (e.g. "CHUNK 9a"). Follow each chunk's steps in order.

## Stack and commands
- TypeScript (strict), Vite, PixiJS v8, Vitest, Playwright (headless Chromium, scripts in `e2e/*.cjs`).
- Check `package.json` for exact script names. Typical: `npm run dev`, `npx tsc --noEmit`, `npm test` (= `npx vitest run`), `npm run test:e2e` (smoke set, tag `smoke`; `-- --area shipyard,freefly` runs the scripts with those tags; `-- --only a,b` reruns named scripts), `npm run test:e2e:all` (every `e2e/*.e2e.cjs`, parallel, chunk 33a), `npm run test:e2e:sheets` (the picture scripts `e2e/sheet-*.cjs`, only when a chunk needs pictures); the runner `scripts/run-e2e.cjs` starts its own dev server (no `npm run dev` needed), `node e2e/<name>.e2e.cjs`, `npm run balance-wall`, `npm run balance-econ`, `npm run balance-damage` (7 min; `PART=a|b|c|d`, `QUICK=1`), `npm run difficulty-audit` (content vs what a player owns, `docs/difficulty-audit.md`; about 1 min from the committed bot cache in `reports/difficulty-audit/`, `FORCE=1` flies the bots again, about 40 min), `scripts/block-audit.ts`, `npm run perf-legendary` (Mirror on a big hull, update times), `npm run perf-profile` (chunk 21b: where a frame goes, in Node, for the owner's slow build; `POOL=8000` tries another pool size), `node e2e/sheet-performance.cjs` (the same build in the browser: sim, sprite sync and draw call), `npm run interaction-audit` (every pair of shape, effect and legendary blocks), `npm run late-tiers` (chunk 27a: the table of tiers 101-200 into `docs/tiers-101-200-table.md`; `PART=bots` flies sample tiers, `PART=reach BUILDS=B,C` finds the highest tier the strong builds pass, minutes).
- Never run `playwright install` (Chromium is preinstalled). npm and pip work; most other network access does not.
- Dev URL flags: `?debug=1` (debug panel, seam line), `?stats=0|1` (stats overlay, also toggled with the backtick key), `?bg=<id>|off` (force or remove the background). Dev hook: `window.__mgbm`.

## Working rules (important)

3. **Keep tests and screenshots lean** (token budget): focused unit tests, at most one new e2e per chunk, contact sheets (one montage image) instead of many screenshots. How many existing e2e scripts to run is set by "Test scope" below.

5. **DECISIONS.md**: append numbered entries for every non-obvious decision or deviation from the prompt. Continue the existing numbering; never renumber old entries (when two branches collide, renumber only the newer ones).
6. **Don't change existing behaviour** unless the chunk says so. Level-1 numbers of existing blocks, saved games, and old tests must keep working. Saves are versioned: bump the version and write a migration, unit-tested, when you change the save shape.
7. If a chunk's spec is ambiguous, choose the simplest reading, write it in DECISIONS.md, and carry on. If a chunk contradicts the code or itself in a way that is expensive to redo, stop and ask.
8. No magic numbers: constants live in `src/wall/constants.ts`, `src/data/*`, `src/config.ts` or equivalent.

## Game design (current state)
**Circuit model.** The Generator (fixed hull cell) always emits a red signal that travels through empty cells as implicit straight pieces. Blocks transform packets in path order and output relative directions (F/L/R). Every block has a STORED orientation and the compiler only reads it (chunk 16a): a block is entered from the side it faces, any other side is a dead end. A new block works out its direction once at placement (it faces the way the signal reaches that cell, `src/engine/orient.ts`) and keeps it; placing, removing or moving a block never re-orients another one. The Auto-orient button is a one-time placement action on the selected block only (the orientation is stored, never recomputed afterwards); Rotate turns it by hand. Old saves (builder save v2, blocks in "auto") are oriented once on load against the circuit as saved. Lines may cross freely, but a block shared by two signals only passes the one entering from the side it faces. Same-axis overlap cuts the later signal. The compiler is in `src/engine/compiler.ts`.

**Blocks.** Data in `src/data/blocks.ts`. Categories: Pathing (blue), Damage (salmon/orange), Modifiers (purple), Status (teal), Mitosis (amber, Free Fly rock mechanics), Legendary (lime, chunk 20a; 66 blocks are shown in all, 13 of them the chunk 20b motion blocks). Only eight blocks have levels (Flat+, Percent x, Lucky Strike, Jackpot, Gambler's Gate, Shield-Breaker, Armor-Piercer Tip, Pure Converter, chunk 16c-2); every other block has one level and runs at its fixed level (`BlockDef.fixedLevel`, table in `src/data/blockEconomy.ts`; the compiler reads it through `powerLevel`). The builder palette and the Shop block list are one shared tile component (`src/builder/tilePalette.ts`): a single scrolling list ordered by category, then data order, no tabs, no category-coloured tile outline, 5 tiles per row. **Shop marks (17a):** brightness never means "owned" in the Shop (only locked tiles are dimmed, with the padlock; the count says what you own); a small yellow dot (#f2c230) in the bottom-right corner of a tile means the next copy can be paid, the cap is not reached and it is not locked (`copyAffordable`); the same dot marks an affordable unowned hull in the hull picker. The builder sheet has no X and no Place button: tap the selected tile again to place it, tap the circuit to close. Every block's copy cap, base price and growth are one table, `BLOCK_ECONOMY` in `src/data/blockEconomy.ts` (16c-2, price family B from `docs/economy-audit.md`): copy price of the n-th copy = base x growth^(n-1) (growth 1.30 normal, 1.15 cheap blocks, 1.20-1.35 for Flat+, the chance blocks and Overclock), upgrade price = base x 2.0 x 2.2^(level-1). Caps: Percent x 10, Flat+ 10, Lucky Strike 6, Jackpot 6, Gambler's Gate 4, Overclock 3, Turn Left / Right 20 each (growth 1.20), Splitter 2 and 3 15 each (growth 1.35 and 1.45; 17b), every status and Mitosis effect block and every block whose extra copy would do nothing 1; the shape blocks that stack have no cap. The shop sheet shows owned / cap and Buy reads "Max" at the cap. **Percent x** is x1.2 per copy at L1 to x2 at L10, geometric in the level (26a; it was x1.5 to x3); **Gambler's Gate** is 40% (L1) to 50% (L3) for x3. **Stacking rule (engine):** every copy of Piercing, Bouncing, AoE Circle / Rectangle, Chain Lightning, Homing, Fork on Impact, Boomerang, Orbit or Mine on a signal's path adds a step (`docs/economy-design.md`, step 5; helpers in `src/engine/effects.ts`); status and Mitosis effects read one level and do not stack. The game shows two short player lines per block (`src/data/blockText.ts`, 19b: one line of at most 60 characters, and for stacking blocks a dimmer "+1 copy: ..." line of at most 40); the long technical text is `BlockDef.desc` and `docs/blocks.md` (`npm run blocks-doc`, regenerate after changing a block). **Interaction rules (17b, `docs/interactions.md`):** every on-hit effect has a trigger in ONE table, `TRIGGERS` in `src/engine/triggers.ts` (status/Mitosis effects: every hit; AoE: every hit (19a; the `shot_end` rule and `ProjectileSystem.retire` are kept but unused); Fork on Impact and Gravity Well: first hit; Chain Lightning: every hit, at most 3 chains per shot; fork copies carry statuses and movement blocks only, no AoE, Fork or Chain). AoE costs the whole shot 5% per extra copy and the builder's estimate shows it. **Chunk 19a:** Piercing is a count, each copy lets the shot through one more target (1 copy = 2 targets) at full damage (`PIERCE_DAMAGE_KEEP` in `effects.ts`), and the shot ends after its last hit; because pierce and bounce are finite, AoE fires on every hit (`docs/interactions.md` section 5). AoE Rectangle is measured in wall cells (`aoeRectCells`: 1 copy 1x3, then alternately a row deeper behind the hit and two wider: 2x3, 2x5, 3x5, 3x7), the Circle's base radius is one cell (`AOE_CIRCLE_CELLS`). Extra copies: Homing a longer seek range and wider cone (19a nerf: one copy 328 px / 33 degrees, three copies the old 400 px / 60), Orbit one more pass, Mine one more mine (up to 3 extra). `npm run interaction-audit` flies every pair of shape/effect blocks (`docs/interaction-audit.md`). **Legendary blocks (20a, `docs/legendaries.md`).** Twelve blocks, one copy each, no upgrades, three per Frontier direction at rings 100 / 200 / 300 (`UNLOCK_BLOCKS` in `src/frontier/unlocks.ts`; a passed or cleared square at that ring or beyond in that direction). They cost Medals AND credits (`LEGENDARY_PRICE_BY_RING` in `blockEconomy.ts`: 15 Medals + 8K, 25 + 65K, 40 + 300K; the Shop sheet shows both, Buy and the yellow dot need both). North: Frontier Echo (+10% of the furthest ring), Payload (+25), Lone Shot (x2 with one shot of yours alive, x1 from ten). East: Last Breath (x2 in the last second of a shot's life), Zigzag (turns every 0.2 s, +5% a change), Heavy Round (x2 at normal speed to x5 at 0.2x). South: Hollow Core (+10% per empty buildable cell), Idle Barrels (+3 per unreached ejector), Waypoint (x1.1 per turn passed). West: Rebound (x4 if the previous shot through the block was weaker), Mirror (every shot cloned), Fuse (10 shots in, one out with double the total). The numbers are in one section of `effects.ts`; compile-time ones read `CompileContext` (furthest ring, empty cells, idle ejectors, `packet.turns`), Lone Shot / Rebound are Gun ops, Fuse is the Capacitor stage with n=10, Mirror is made in `Gun.spawn` (never from a hit, so never cloned again; `TRIGGERS.mirror`). **Frontier unlocks are legendary-only (20b).** The Frontier unlocks the twelve legendary blocks and nothing else (`UNLOCK_RINGS` = 100 / 200 / 300, three blocks per direction; the map draws only those three rings). **Campaign-tier locks (20b, `src/data/tierLocks.ts`, `TIER_LOCKS`):** a block can need a PASSED campaign tier (padlock and text "Pass tier N" in the Shop and the builder picker, same as the Frontier lock; a "Unlocked: X" toast when a tier passes). Grandfathering: a save that owns a copy keeps buying, a save that had reached the block's old Frontier ring (`LEGACY_RING_GATES`) keeps it. 26 blocks have a tier: Accelerator 5, Brake 15, Scatter 15, Upturn 20, Align 25, Extender 30, Centreline 40, Ship Magnet 45, Persist 50, +1 Projectile 10 (21a) and the 16 ordinary blocks that used to sit at Frontier rings 10 / 25 / 50 (Cleaver 5 ... Chain Lightning 60, full table in `docs/blocks.md`). **Motion blocks (20b, `docs/motion-blocks.md`):** thirteen Modifier blocks that change how a shot moves: Curving Left, Angle Left / Right (15 degrees a copy, max 60; `packet.angle`), Accelerator (x1.5, cap 3, ceiling x4), Brake (x0.7, floor 0.2; Heavy Round reads it), Scatter (random cone +-30, +15 a copy, max 60), Upturn (turns back to straight up after 0.4 s), Align (straight up after a surviving hit), Extender (life x2 a copy, `pool.life`; Last Breath follows it), Centreline (pull toward the x the shot was fired from), Ship Magnet (the old hidden `magnetized` block; pull toward the ship, speed capped at the launch speed), Persist (spends the damage a target had left, goes on through kills). (Reverse was removed in 21a.) A fast shot is checked along its whole step (`ProjectileSystem.sweep`, swept hit test). Free Fly now retires every shot at its `life`. On a hit the order is Persist, Piercing, Bouncing, end (`docs/interactions.md` section 7). The numbers are one section of `effects.ts` ("Chunk 20b"). Save version 9 until 21a (now 10). More blocks are hidden until added by a chunk.

**Chunk 21b (`docs/performance.md`, DECISIONS 372-384).** **Performance.** The owner's slow build (10 +1 Projectile, Mirror, Fork, 2 Extender, 2 Bouncing, 3 Homing) was profiled first (`scripts/perf-profile.ts`, `e2e/sheet-performance.cjs`, builds in `scripts/lib/perfBuild.ts`): on the tier-100 wall Homing cost 21 of 22 ms a frame at 4,000 shots (every homing shot listed every block in 400 px, every frame); in Free Fly the cost was the hit test's allocations. Fixed: **Homing keeps its target** (alive, in range, in the cone) and with none searches at most every 0.1 s, the first search staggered by pool slot (`homingTurn`, `HOMING_RETARGET`, `HOMING_STAGGER`); the search is a radius query on the field (`TargetField.nearestInCone` / `byId`, `ListField` is the brute-force reference for plain lists); `SpatialHash` is flat typed arrays with `queryInto` (no list per query); the world keeps one hash and one `EnemyField` (`refresh()`); the modifier-list facts are cached per list (`ModInfo`, `use()`), no per-shot `find`; `ProjectilePool.spawn` starts from a free-slot hint. Wall at 4K shots 22.5 -> 2.95 ms, Free Fly 3.5 -> 2.3 ms (Node); in the browser the wall at a full pool went from 3 fps (a catch-up spiral, 268 ms of sim) to 26. **Graceful overload** (`CONFIG.OVERLOAD`): new shots are refused as the pool fills, in this order: fork fragments (80 % of the pool), Mirror clones (88 %), the extra shots of +1 Projectile (`EjectorRecipe.extra`, 94 %), normal shots only at 100 % (`pool.admits(kind)`, `pool.refused`); from 85 % plain shots that are off-screen (`projSys.viewCx / viewHalfW / viewTop / viewBottom`, set by the wall screen from the camera) and have hit nothing for 1.5 s expire first (`expireStale`, at most 400 a frame). **The pool limit stays 4,000** (`CONFIG.CAPS.PROJECTILES`): at 4K the build is already at about 8 ms of sim plus render in the browser. **Shot looks (redrawn):** five bands, each its own shape and colour: under 10 a thin cyan dash, 10-99 a longer pale-cyan bar, 100-999 a yellow diamond, 1K-9.9K an orange bolt, 10K+ a magenta four-pointed star (`SHOT_LOOKS` in `src/ui/shotLook.ts`); Orbit, Boomerang and Mine keep the plain bar (`PLAIN_LOOK`). `src/ui/shotSprites.ts` draws every shot of a pool for both fly screens: one white texture per shape, tinted; texture, size and colour are set only when a shot's look changes; shots outside the view are hidden. **Run summary:** Destroyed / Time / Result (or the four Free Fly rows), Best shot and Average DPS are rows of one style, then the Total credits line, the captain line and the buttons (at y 800, `SUMMARY_BUTTONS_Y`; e2e scripts tap y 832).
